Remaining time prediction estimates how long an ongoing case, such as an order or application, will take to finish. We combine process models with information from similar past cases to make these estimates.

## Enhancing Stochastic Petri Net-based Remaining Time Prediction using k-Nearest Neighbors

*ATAED / Petri Nets 2022.*

We select past cases with similar activity timings and use them to build a process model with timing distributions. Simulating this model gives a remaining-time estimate tailored to the current case.
